About TV Energy

TV Energy is a fictional project built to demonstrate core web development skills, including structuring pages with HTML, applying consistent styling with CSS, and adding interactivity with JavaScript as part of a university unit.

Purpose

Why this site exists

This three-page site was built to practise multi-page HTML structure, shared CSS styling, and DOM-driven JavaScript interactivity, including an accordion FAQ and an appliance energy calculator.
